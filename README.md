# إدارة مزرعة العصافير — V2

نسخة أولية مستقلة لتطبيق ويب عربي يعمل كتطبيق PWA.

## الملفات
- `index.html`: واجهة التطبيق والمنطق الأساسي.
- `manifest.webmanifest`: إعدادات التثبيت.
- `sw.js`: التخزين المؤقت ومحاولة فتح الواجهة دون اتصال.
- `icon-192.png` و`icon-512.png`: أيقونات التطبيق.

## التشغيل
ارفع الملفات الخمسة إلى جذر مستودع GitHub جديد، ثم اربطه بمشروع Cloudflare Pages.
إعدادات البناء:
- Framework preset: None
- Build command: اتركه فارغًا
- Build output directory: `/` أو `.` حسب واجهة Cloudflare

## تنبيه مهم
هذه نسخة تأسيسية وليست النسخة النهائية. التخزين الحالي محلي في المتصفح (`localStorage`)؛ لذلك يجب تنزيل نسخة احتياطية من صفحة «النسخ الاحتياطي» بانتظام. لا توجد مزامنة بين الأجهزة حتى الآن.
الإشعارات المجدولة، إدارة الأزواج التفصيلية، سجلات التفريخ المتقدمة، الصور، والنسب الحسابية الدقيقة لخلطات الحبوب تحتاج مراحل تطوير واختبار لاحقة.
